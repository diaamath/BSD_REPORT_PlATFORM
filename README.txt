طريقة الاستخدام:
1) افتح index.html بالمتصفح (Chrome/Edge) بنقرتين.
2) ارفع ملف الإكسل.
3) للتعديل افتح الملفات بـ VS Code أو Notepad++ (وليس بالمتصفح):
   settings.js  = الإعدادات وأسماء الأعمدة وبيانات الفصل السابق
   engine.js    = الحسابات
   render.js    = شكل الصفحات والنصوص
   style.css    = الألوان والتصميم
بعد كل تعديل: احفظ الملف ثم حدّث الصفحة (F5).
